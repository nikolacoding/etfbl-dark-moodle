# Instalacija (brzo i jednostavno):

### 1. Skini i otpakuj
Iz **Releases** menija s desne strane preuzmi fajl `etfbl-dark-moodle.rar` i **otpakuj (unzip)** ga na računaru. Idealno preuzmi onaj koji odgovara najskorijoj verziji.

### 2. Otvori Extensions (Chrome, Brave, Opera...)
U adresnu traku ukucaj (ili prosto kopiraj) `chrome://extensions/` i pritisni **Enter**.

### 3. Uključi Developer mode
U gornjem desnom (ili lijevom) uglu stranice uključi **Developer mode**.

### 4. Učitaj
Klikni na **Load unpacked** i izaberi otpakovani folder.
